# LSPD MDT Pomocník

Pomocník pro MDT – LSPD (FiveM RP).

Z této složky si aplikace stahuje **automatické aktualizace**. Celý program pro první instalaci je ZIP, který rozesílá správce.

Aktuální verze: **1.1.0**

## Co je nového
- Nová ikona aplikace
- Plovoucí kalkulačka trestu – Ctrl + Shift + M ji ukáže i nad hrou (hra v režimu okno bez okrajů)
- Z kalkulačky jde přestupky jedním klikem poslat do hlášení
- Automatické aktualizace – nové verze se nabídnou samy, data zůstanou
