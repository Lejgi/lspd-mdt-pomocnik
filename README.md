# LSPD MDT Pomocník

Pomocník pro MDT – LSPD (FiveM RP).

Z této složky si aplikace stahuje **automatické aktualizace**. Celý program pro první instalaci je ZIP, který rozesílá správce.

Aktuální verze: **1.2.4**

## Co je nového
- Vysílačka – mezi sloupce kódů přibyly svislé čáry pro lepší přehled
